# 🤖 KERONG Penguin

> ⚠️ **此插件是 HuHoBot 的魔改分支**（源码已按 HuHoBot 上游结构重写为可读的 Kotlin 工程）

Minecraft QQ 机器人插件，通过 QQ 官方机器人 API 实现 QQ 群与服务器的深度交互。

## 功能

- **QQ 绑定验证** — 玩家进入服务器前需绑定 QQ，5 位随机绑定码验证
- **个人信息统计卡片** — QQ 群发送 `/个人信息`，渲染毛玻璃风格 15 项生涯统计卡片（金币/游戏时长/击杀/签到等），支持多张背景图随机切换；`/查信息` 保持原版行为（查询 OpenId，用于配置 bot.groups）
- **玩家统计自记录** — 实时累计游戏时长、击杀、死亡、挖掘、距离等数据，定时异步保存，对性能几乎零影响
- **AI 对话** — QQ 群 @机器人 或服务器内输入前缀触发，支持 DeepSeek/OpenAI
- **黑名单系统** — 管理员可将 QQ 加入黑名单，自动解绑并踢出
- **快捷指令面板** — QQ 群快捷指令菜单，根据配置动态显示
- **在线查询** — 自定义 .md 模板渲染在线玩家列表（图片自动加时间戳防缓存）
- **消息转发** — QQ 群 ↔ 游戏双向消息转发
- **自定义执行指令** — QQ 群触发自定义服务器命令
- **群内签到** — @机器人 /签到 领取金币奖励（需 Vault，离线暂存自动发放）

## 环境

- Java 17+
- Spigot / Paper / 混合端（Mohist、CatServer、Arclight 等，自动检测命令执行器）
- QQ 最新版（支持机器人功能）

## 从源码构建

```bash
./gradlew :server-Spigot:jar   # 编译两个模块
python3 scripts/package_jar.py # 合成可分发的 fat JAR（可选）
```

> 依赖的第三方库（kloping QQ SDK、fastjson 等）以 `libs/deps.jar` 形式提供编译期引用，
> 打包时复用原版 JAR 中的依赖字节码。

## 项目结构

```
common-Bot/      # 机器人核心（QQ 客户端、群命令、状态持久化、QQ 绑定管理）
server-Spigot/   # Spigot 平台适配（主类、命令执行器、事件监听、配置管理、卡片渲染）
```

### v1.5.0 更新日志（含 1.4.5 → 1.5.0 全部更改）

**本次修复 / 新增（1.5.0）**

- **修复**：信息卡片图片有概率加载失败 —— 背景图缩放的浮点截断会使裁剪区域越界
  （`RasterFormatException`），随机背景下偶发卡片生成失败；现改为向上取整并保证
  裁剪恒在图像范围内，任何尺寸背景图均稳定生成
- **修复**：称号无法检测 —— DeluxeTags 对接改为宽容反射（按方法名匹配并自适应参数
  类型，兼容不同版本的 API 重载）；在线玩家直接取游戏内实际显示的标签（含默认 /
  强制 / 玩家自选），离线玩家回退到持久化保存的选择；称号里的占位符文本自动剔除
- **新增**：统计项 **累计签到**（本插件签到系统的累计次数）与 **点券**
  （PlayerPoints 插件点券余额；未检测到相关插件时显示“未启用”）
- **优化**：图片渲染改为 CPU 异步多线程 —— 多人同时查询时并行出图互不排队
  （单线程限流会导致多张图片堆积反而卡服，故不再限制渲染核数）；空闲线程 60 秒
  后自动回收，不占常驻资源
- **优化**：渲染完成后释放 JVM 内存 —— 单次渲染画布立即 flush 释放栅格，
  并做节流 GC 提示（两次至少间隔 60 秒，`qq-bind.render.gc-after-render` 可关）
- **优化**：同一玩家在 `qq-bind.render.result-cache-seconds`（默认 60 秒，0 关闭）内
  重复查询直接复用上次渲染的图片，零渲染开销秒回；配合单用户 5 秒查询冷却、
  背景 / 头像缓存，连续查询不再拉高 CPU 与内存

**QQ 机器人稳定性（0.1.5.x 系列）**

- 修复两轮"机器人无法连接 / 命令无响应"（JAR 打包目录条目缺陷，SDK 组件装配失败）
- 修复断线永久掉线 —— QQ 网关正常关闭连接（code 1000）后自动 3 秒重连，
  并有常驻看门狗兜底（持续断开超 1 分钟自动触发重连并记录日志）
- 修复头像正面贴图解析、绑定艾特 / 解绑踢出 / 黑名单踢出等交互问题

**信息卡与统计（0.1.5.x 系列）**

- 新增 QQ 群 `/个人信息`：毛玻璃风格图片卡片，统计为 **金币、称号、在线时长、
  今日在线时长、累计签到、点券** 6 项；背景图放入 `plugins/KERONGPenguin/img/`
  每次随机挑选，超大图片自动子采样解码（防内存溢出），无图时黑色背景
- 称号颜色真实还原：`&` / `§` 颜色码与 `&#RRGGBB` 十六进制色按原色渲染到卡片，
  过暗颜色自动提亮，超长自动截断
- 玩家统计实时累计、定时异步保存，对服务器性能几乎零影响

**日志与排障（0.1.5.x 系列）**

- 全部警告 / 报错双写控制台与插件日志文件 `logs/qq/qq-bind-日期.log`
  （卡片生成失败附带堆栈前几帧，事后可完整追溯）
- 机器人连接过程日志（初始化 → 鉴权 → 装配 → 连接成功 / 超时）落盘；
  数据保存汇总日志仅写文件不刷控制台

**其他（0.1.5.x 系列）**

- `command-sender` 默认 `Auto`：自动检测混合端（Mohist / CatServer / Arclight 等）
  并选择合适的命令执行器
- 源码按 HuHoBot 上游结构重构为可读 Kotlin 双模块工程（common-Bot + server-Spigot）
