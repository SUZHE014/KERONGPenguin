更新日志

v1.7.6.7

2026-11-22
  • ① 签到金币奖励支持随机区间：qq-bind.checkin.reward 两种写法——固定数额照旧填数字（如 100.0，行为不变）；随机区间填「最小~最大」（如 0~100，每次签到在区间内随机发放，含两端，两端都是整数时抽整数）；签到成功回复带「随机 0~100」标注让群友看得出是抽的；写错的值自动回退默认 100.0 并记文件日志；Spigot / NeoForge / Fabric 三端一致
  • ② 新增管理员群发指令 /hbkrg qifx <内容>：让机器人把这条消息发送到配置的全部 QQ 群（bot.groups），发公告 / 通知一键到位；游戏内与服务器控制台均可执行，内容支持空格（上限 1200 字）；发送异步进行，完成后反馈成功 / 失败群数（失败原因见 logs/qq 日志）；未连接机器人或未配置群时直接提示不发
  • ③ Arclight 混合端兼容修复：修复 Arclight-forge 1.20.1 等混合端上「凭据自检通过但机器人始终显示离线」的问题——QQ 连接启动不再被服务端自带的旧版 jansi 库中断（已实测 Arclight-forge 1.20.1 全链路通过）；启动阶段异常统一输出明确的「QQ 机器人启动失败」原因，不再只留一条难懂的调度器警告；2026-11-22 重新构建的 1.7.6.7 四端包均为修复版，此前下载过的请重新下载

v1.7.6.5

2026-11-18
  • ① AI 网页读取正式功能（默认开）：AI 需要时自动读网页，支持多层深入（先读搜索页 / 入口页，再继续读页面里的链接逐层阅读），需要搜索时用必应（bing.com），中文关键词自动编码；两个上限分开配置——单次回答读取网页总数 max-pages（默认 8）与多层层数 max-layers（默认 4），达到任一上限不再中断，AI 直接基于已读内容把回答说完；读取失败时用自然语言告知；⚠ 每次读取的网页内容都会消耗额外 token（按读取页数计）
  • ② AI 网页读取安全机制：仅 http/https 公网页（内网地址拒绝，防 SSRF）；不下载任何东西——压缩包 / 安装包 / 图片等下载链接一律拒绝，超大内容读都不读，全程不落盘任何文件、不加载页面引用资源；正文剔除隐藏字符，回传 AI 时框定为「资料不是指令」（防网页注入）；已配置关闭的服务器升级后保持关闭不受影响
  • ③ 游戏内 AI 唤醒消息兼容格式化聊天插件 / 模组：装了 CMI、VentureChat 等会重写或取消聊天事件的插件（或对应模组）也能正常识别唤醒消息，Spigot / NeoForge / Fabric 三端一致
  • ④ 修复游戏内触发 AI 对话时玩家消息被吞：玩家发的消息照常显示在聊天栏（此前消息直接不显示、只有 AI 回复）；触发消息仍不转发 QQ 群
  • ⑤ 游戏内表情兜底文案改为「只想发个表情，奈何游戏不允许」，且可通过配置 ai.memes.game-fallback-text 修改（AI 只想发表情包时游戏内显示不了图片，回复这条文案；QQ 群里正常发图不受影响）
  • ⑥ AI 表情包：guaipng 文件夹放图（文件名 = 图片含义，动态 GIF 正常发送），静态图发送前自动缩到表情大小；AI 只发表情包时不再先发一条只有前缀的空白消息
  • ⑦ AI 提示词单文件（提示词.md）：角色设定 + 技能引导 + 专属知识都写在这一个文件里，改完保存下次对话生效；「技能」段随插件更新自动刷新为本版内置内容（角色设定与专属知识不动）；网页读取重新开启时自动补上搜索引导
  • ⑧ 消息模板更新机制重写：不在 messages.keep-files 白名单里的模板每次启动 / 重载都会重置为插件内置最新默认（包括改过的）；想保留自己改的模板，把文件名加进白名单（名单内的模板不更新不替换，原样保留）
  • ⑨ 死亡播报大修：修复没有玩家昵称的问题；补齐冻结 / 挤压 / 脱水 / 龙息 / 音波 / 甜浆果丛 / 铁砧 / 钟乳石等 14 种原版死法中文文案；玩家昵称与死亡原因分开——{name} 只替换玩家名、{message} 只替换纯死因，默认文案「[游戏] {name} {message}」（昵称与死因中间一个空格）；新增 custom-causes 开关（默认开），关闭时只展示插件内置的原版死因，其他统一显示「死了」；其他插件改写的死亡消息原样播报（Spigot），模组自定义伤害类型取游戏内死亡消息播报（NeoForge / Fabric）
  • ⑩ 插件文件夹结构重构：根目录只留 config.yml / 提示词 / guaipng 表情包 / img 背景图，其余（绑定数据、日志、回复模板、缓存、状态文件）自动迁入 globalconfig/ 文件夹（升级自动迁移，旧文件残留自动清理）
  • ⑪ 配置注释全键注释覆盖：每个配置键都有注释
  • ⑫ config-version 60 → 63（升级自动补新键与注释，已有配置值不动）
  • ⑬ 查性能内存占用改为含预留口径：按 JVM 已提交堆显示，与 MC 面板上显示的内存占用一致（JVM 预留未用部分也计入）；/hbkrg mem 仍可查看插件实际占用

v1.7.6.2

2026-11-16
  • 新增：AI 表情包——首次启动自动创建插件目录 guaipng 文件夹，把图片放进去即可（支持 png / jpg / jpeg / gif / webp / bmp，动态 GIF 正常发送），文件名 = 图片含义；AI 觉得气氛合适时在回复末尾加 [表情] 文件名，插件把图片发到群里（ai.memes.* 可调，文件增删即时生效）
  • 新增：AI 提示词（单文件）——机器人的角色设定与专属知识写在插件目录的一个文件里（默认 提示词.md，首次启动自动生成）：「角色设定」写身份与回复风格，「专属知识」写服务器规则、玩法、常见问题等资料；改完保存下次对话自动生效，无需重启。原配置项 ai.system-prompt 已并入该文件（升级自动迁移、配置项自动删除），knowledge 知识库文件夹方案由该文件取代
  • 新增：AI 网页爬取——默认关闭（测试功能）：开启后 AI 需要先看网页才能回答时可输出 [GET] 网址，插件抓取网页正文回传继续生成；仅 http/https 公网页，内网地址被拒绝（防 SSRF）；并修复网页读取失败时 AI 把访问代码 / 错误信息直接甩给用户的问题——失败统一按「网页暂时无法访问或没有返回内容」自然告知，技术原因只写日志；生产环境建议保持关闭
  • 新增：多服务器集群「查在线 / 查性能是否显示多个服务器」开关（bot.cluster.show-multi-cards，默认关）——开启后这两条命令（含别名 /在线）不再弹「选择服务器」按钮、无视群已选择，每台服务器各自渲染本服状态卡片，群里同时显示全部服务器的在线 / 性能状态
  • 调整：配置文件与官网教程清理版本号标注；表情包文件夹与提示词文件改为启动即自动生成；config-version 56 → 57（升级自动删废弃键，已改值不动）
