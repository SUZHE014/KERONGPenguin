更新日志

v1.7.6.2

2026-11-15
  • 新增：AI 表情包——把图片放进插件目录 guaipng 文件夹（支持 png / jpg / jpeg / gif / webp / bmp，动态 GIF 正常发送），文件名 = 图片含义；AI 觉得气氛合适时在回复末尾加 [表情] 文件名，插件把图片发到群里（ai.memes.* 可调，文件增删即时生效）
  • 新增：AI 知识库——把 txt / md 文本文件放进插件目录 knowledge 文件夹（空行分段），群里 @机器人 提问时最相关的段落自动注入给 AI 作答依据（ai.knowledge.* 可调，文件增删即时生效，空目录零影响）
  • 新增：AI 网页爬取——默认关闭（测试功能）：开启后 AI 需要先看网页才能回答时可输出 [GET] 网址，插件抓取网页正文回传继续生成；仅 http/https 公网页，内网地址被拒绝（防 SSRF）；能力说明与配置注释均带测试功能警告，生产环境建议保持关闭
  • 新增：多服务器集群「查在线 / 查性能是否显示多个服务器」开关（bot.cluster.show-multi-cards，默认关）——开启后这两条命令（含别名 /在线）不再弹「选择服务器」按钮、无视群已选择，每台服务器各自渲染本服状态卡片，群里同时显示全部服务器的在线 / 性能状态

v1.7.6.1

2026-11-15
  • 修复：在线排行榜不再计入假人插件（minecraft-fakeplayer 等）假人的时长——本地注入连接（地址为空 / 回环 / 内存连接）自动识别登记，离线假人的历史时长同样排除；真人以真实外网连接进服自动恢复上榜；假人白名单（qq-bind.fake-player-whitelist）命中的同样生效
  • 新增：查在线假人列表开关 online-list.show-fake-players（默认关）——开启后主列表只显示真实玩家，底部额外显示「假人在线」小节列出当前在线的假人；文字列表模式同开关同口径（人数只算真实玩家 + 末尾假人摘要行）
  • 调整：假人白名单 qq-bind.fake-player-whitelist 全端生效——Fabric 端跳过未绑定限制照旧，所有端都用它识别假人
  • 配置版本 54 → 55，升级自动补新键（已改值不动）

v1.7.6

2026-11-15
  • ① 在线排行榜「服务器存档数据」源改为直接枚举服务器自己的全部玩家数据——不再先经 QQ 绑定记录，没开 QQ 绑定的服务器也能出榜；usercache.json 全量玩家逐个读存档统计，usercache 条目被服务器清理但统计文件还在的老玩家用绑定记录补名字照常上榜；同名玩家（改名前的旧账号 / 多个同名）每个存档账号各占一行同时显示
  • ② 总在线时长获取源默认改为「服务器存档数据」（save-data）——玩家名片读取不到自动回退变量 → 插件统计；在线排行榜直接枚举服务器数据（不依赖 QQ 绑定）；旧配置升级自动收敛为存档源（自行选过插件统计 / 变量的不动），config-version 53 → 54
  • ③ 修复 bot.groups 群列表只写一对双引号 ""（或纯空白 / 纯引号）被误判为已填写——现在视同未填写：自动绑定正常触发、群白名单不再恒不匹配
  • ④ 排行榜存档收集汇总写日志（logs/qq 的「[存档统计] 排行榜直枚举」行：usercache 命中数 / stats 目录补充数 / 无名字可补跳过数），排障直接对照

v1.7.5.7
