更新日志

v1.7.5.1

2026-11-10
  • 修复：连点几个菜单按钮后机器人不再回复——QQ 对同一条消息的被动回复有次数上限（约 5 条），连续点击的回复全部引用同一条消息很快触顶被平台拒收（错误码 40034128「被动回复时间或者次数超过限制」）。现在插件记住群里最近 16 条真实消息，连续点击轮流引用不同消息（配额放大 16 倍）；万一仍被拒收，自动转主动消息通道补发，回复一定能到达。
  • 修复：管理员点菜单按钮提示没权限——QQ 按钮点击的回调不携带点击者的群身份（群主 / 管理员 / 成员），手打命令时的管理员判定在按钮路径全部失效（群主点管理类按钮也提示无权限）。现在插件从最近的真实消息记住每位成员的群身份，点击按钮与手打命令的权限判定完全一致。
  • 修复：老安装的消息模板没有随版本更新——模板升级比对放宽：空白差异容忍 + 默认特征识别，历史任何一版默认模板都会自动刷新到最新口径（自己改过的模板依然不动）。
  • 修复：偶发 QQ 提示「第三方连接失败」——官方要求按钮点击后 3 秒内回应，旧实现连接超时设 4 秒且失败不重试，网络稍一抖动就超出窗口；现收紧到 1.5 秒并在网络抖动时快速重试一次，两次机会都落在 3 秒窗口内。
  • 修复：/全量 切换后 QQ 快捷面板的全量按钮没有立即出现 / 消失——现在切换后自动按新配置重同步全部配置群的面板，无需 /hbkrg reload 或重启。
  • 版本号 1.7.5.1（同日小版本）；配置版本保持 43，升级无需改配置。

v1.7.5

2026-11-10
  • 新增：/菜单 按钮菜单——替换原 /帮助 命令列表。发送 /菜单 输出全部可用命令的按钮（一行一个，超过一页点「下一页」翻页）：查在线 / 查性能 / 玩家名片 / 在线排行榜 / 签到等无参数命令点一下直接执行（机器人收到点击后立即执行并回复结果，无需再手动发送）；需要补参数的命令（绑定 / 发信息 / 执行命令 / 执行 / 管理员执行）点击后复制到输入框，补全内容后发送。按钮可见性与快捷面板同一套开关，关闭的功能按钮同步消失。
  • 修复：点击回调按钮 QQ 显示「操作成功」但机器人没有反应——真根因是以点击者身份执行命令时缺少群标识字段（SDK 实际读取 group_id，旧版只写了 group_openid），群白名单校验把命令拦下从未执行（互动回应已发出所以 QQ 显示操作成功）。现补齐后点击与手打命令完全一致；命令回复也改走被动通道（复用本群最近真实消息 id，不受主动消息配额限制）。
  • 修复：所有按钮点击后只是复制到输入栏、不能直接互动——QQ 官方限制：群聊里「指令按钮」的自动发送（enter）只对单聊生效，群聊点击指令按钮只会把 @机器人 + 命令填进输入框。现按命令分流：无参数命令用回调按钮（点击 → 机器人执行 → 群里直接收到结果，一步到位）；需补参数的命令用指令按钮（点击复制进输入栏，补全后发送——这类命令点回调只能得到一句用法提示，不如直接填进输入框）。
  • 修复：按按钮后 QQ 弹「第三方连接失败」（机器人却正常执行了操作）——官方要求按钮点击后 3 秒内回应；排查发现机器人 SDK 的回应请求实际以错误方式发出（声明 PUT 的接口被当成无内容 GET 发送，被平台 405 拒绝，且 SDK 不报错），回应从未真正送达。现改为绕开 SDK 直发标准 PUT 回应，点击按钮不再弹任何报错；回应语义对齐官方（操作成功 / 操作失败 / 重复操作 / 没有权限）。
  • AI 命令合并为 /AI管理——原「/AI对话上下文 开|关」与「/清除当前上下文」两条命令合并为 /AI管理（可带参数 开|关|清除）；发送 /AI管理 显示当前状态并弹出三个按钮（一行一个）：开启上下文 / 关闭上下文 / 清除上下文，点击即执行。AI 功能（ai.enabled）关闭时该命令同步关闭；QQ 快捷面板按钮同步合并。
  • 黑名单按钮——/黑名单 与 /解除黑名单 不带参数时输出同一张按钮清单：每个条目一行一个「解除」按钮，点击即移出（也可艾特对方发送命令解除）；超过 5 条自动换网格排布，人人都有按钮。全部消息按钮统一蓝色样式。
  • 消息模板自动升级——历史版本的默认模板文案（如黑名单列表的解除提示、AI 管理状态文案）首次释放后一直不覆盖，老用户看到的是旧文案；现在仍是旧默认内容的模板升级时自动刷新为新默认（自己改过的模板不受影响）。
  • 修复：模组版更新检查一直提示发现 1.7.4.x 新版本（内部版本号常量漏升，现与插件版本一致）；更新检查的更新日志只显示当前新版本内容，不再输出历史版本记录。
  • 全量转发改为总开关——features.full-amount 对 bot.groups 里全部群统一生效（不再按群独立记忆）；/全量 直接切换总配置并写回 config.yml；群级独立开关已删除（旧状态段自动清理）；总开关关闭时 /菜单 与 QQ 快捷面板的全量按钮同步隐藏。
  • 官网与源码注释清理：移除全部版本更新轮次与版本新增标注字段。配置版本 40 → 43（commands.帮助 → commands.菜单、commands.AI对话上下文 + commands.清除当前上下文 → commands.AI管理，开关值自动迁移，旧配置无需改动）。

Fabric 测试版 1.7.4.1（MC 1.20.4，Java 21）

KERONGPenguin 的 Fabric 适配版——与 Spigot / NeoForge 版同源同功能：群聊互通 / 查询命令 / 信息卡渲染 / 绑定签到 / 服务器状态播报

  • 测试版定位：功能与主线 1.7.4.1 对齐，但未经长期实测；遇到问题请换回 Spigot / NeoForge 版并反馈。
  • 主系已测试版本：1.20.4，1.21，1.21.6。
  • 支持版本：1.20.4 及以上（fabric.mod.json 声明 ≥1.20.4，更高版本未实测）；Fabric Loader 0.15.0 及以上（构建验证基于 0.16.14）；需另装 Fabric API（与所用 MC 版本对应即可）；Java 21。
  • 安装：与 Fabric API 一起放进 mods/ 即可；配置文件在 kerongpenguin/ 目录（首次启动生成），与插件版同结构可参考教程。
  • 测试版差异：登录绑定不做配置阶段拦截（未绑定玩家加入后踢出）；钓鱼 / 繁殖动物统计暂缺。
