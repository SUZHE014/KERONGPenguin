更新日志

v1.7.6.4

2026-11-17
  • 调整：消息模板更新机制重写——不在白名单里的模板文件每次启动 / 重载都会删掉重置为插件内置最新默认（包括改过的）；想保留自己改的模板，把文件名加进配置 messages.keep-files 白名单（名单内的模板不更新不替换，保留原样）
  • 修复：cluster-selection.yml、command-state.ini、server-notify-state.properties 等状态文件补迁移——随其余数据一并迁入 globalconfig/ 文件夹（升级自动迁移，旧根目录文件自动搬走）
  • 新增：AI 网页读取重新开启时自动更新提示词——已生成的提示词.md 自动补上「读网页与搜索」技能引导（只在开启且缺这一行时补一次，其余内容不动）
  • 修复：死亡播报没有玩家昵称——{message} 自动带上玩家名（如「Steve 从高处摔落而死」）；自定义文案里已有名字不会重复拼
  • 新增：死亡播报支持更多死亡原因——补齐冻结 / 挤压 / 脱水 / 龙息 / 音波 / 甜浆果丛 / 铁砧 / 钟乳石等 14 种原版死法中文文案；其他插件改写的死亡消息原样播报（Spigot），模组自定义伤害类型取游戏内死亡消息播报（NeoForge / Fabric）
  • config-version 60 → 61（升级自动补 messages.keep-files 新键与注释，已有配置值不动）
  • 修复：游戏内触发 AI 对话时玩家消息不再被吞——玩家发的消息照常显示在聊天栏（此前消息直接不显示、只有 AI 回复），三端一致；触发消息仍不转发 QQ 群
  • 调整：游戏内 AI 只想发表情包时的兜底文案改为「只想发个表情，可奈何游戏不允许」
  • 调整：死亡播报玩家昵称与死亡原因分开——{name} 只替换玩家名、{message} 只替换纯死亡原因，默认文案改为「[游戏] {name} {message}」（昵称与死因中间一个空格）；插件 / 模组自定义文案开头的玩家名自动剥掉不重复（旧默认配置升级自动收敛，自改过文案的不动）
  • 新增：死亡播报配置开关 custom-causes（默认开）——关闭时死亡原因只展示插件内置的原版死亡原因，其他死亡原因统一显示「死了」
  • config-version 61 → 62（升级自动补 custom-causes 新键与注释，已有配置值不动）

v1.7.6.3

2026-11-16
  • 新增：AI 网页读取正式功能（默认开）——AI 需要时自动读网页，支持多层深入（先读搜索页/入口页，再继续读页面里的链接），需要搜索时用必应（bing.com），中文关键词自动编码；两个上限分开配置：单次回答读取网页总数 max-pages（默认 8）+ 多层层数 max-layers（新增，默认 4）；达到上限后 AI 直接基于已读内容作答（不再中断）；网页读取失败时用自然语言告知；⚠ 每次读取消耗额外 token（按读取页数计）
  • 新增：AI 表情包（guaipng 文件夹，文件名 = 图片含义，动图 GIF 正常发送）；静态图发送前自动缩到表情大小（约 240px 转 GIF，QQ 按表情尺寸渲染，与动图表情一样大）
  • 新增：AI 提示词单文件（提示词.md，角色设定 + 专属知识都写在这，改完保存下次对话生效）
  • 调整：重构插件文件夹结构——根目录只留 config.yml / 提示词 / guaipng 表情包 / img 背景图，其余（QQ 绑定数据、日志、回复模板、缓存）自动迁入 globalconfig/ 文件夹（升级自动迁移，无需手动搬运）
  • 调整：配置注释精简且全键注释覆盖（每个配置键都有注释）；恢复 ai.memes.max-per-reply / ai.crawler.timeout-seconds / ai.crawler.max-chars 三键；config-version 59 → 60（升级自动收敛：读取上限旧默认 2/3 自动升 8，自定义值不动）
  • 新增：AI 提示词默认带技能引导——新装默认模板新增「技能」段（AI 拥有的技能列表 + 「遇到不会、没把握或时效性的问题，先搜索再回答，不要凭记忆猜测，也不要直接说不知道」）；对话内系统技能段同步重写为「你拥有的技能如下」，动态注入立即生效（已有提示词文件不覆盖，可参考新默认模板自行补段）
  • 修复：AI 只发一个表情包时不再先发一条只有「[AI]」前缀的空白消息——直接发表情包图片；表情没匹配到图片（可检查表情包文件夹）或图片发送失败时发一句文字说明兜底；游戏内对话同步修复（不再广播空白）
  • 调整：AI 网页读取（搜索）默认改为关——新装默认不开启；已开启的服务器保持开启不受影响，想关在配置里改 ai.crawler.enabled: false 即可；老版本升级也不再被强制打开
  • 调整：提示词里的「遇到不会的可以搜索」技能引导仅在 AI 网页读取开启时才生成（默认模板按当前开关写入；关闭时对话内系统技能段也不注入搜索条目，不引导 AI 去用没有的功能）；已生成的提示词文件不自动改动
  • 修复：插件数据迁入 globalconfig/ 后旧文件残留——同名冲突时旧版直接跳过（旧文件与旧目录永久留在插件根目录），现在按修改时间取较新内容、另一份自动删除；文件被占用导致移动失败时自动改为复制后删除，仍有残留会在控制台提示并下次启动重试

v1.7.6.2

2026-11-16
  • 新增：AI 表情包——首次启动自动创建插件目录 guaipng 文件夹，把图片放进去即可（支持 png / jpg / jpeg / gif / webp / bmp，动态 GIF 正常发送），文件名 = 图片含义；AI 觉得气氛合适时在回复末尾加 [表情] 文件名，插件把图片发到群里（ai.memes.* 可调，文件增删即时生效）
  • 新增：AI 提示词（单文件）——机器人的角色设定与专属知识写在插件目录的一个文件里（默认 提示词.md，首次启动自动生成）：「角色设定」写身份与回复风格，「专属知识」写服务器规则、玩法、常见问题等资料；改完保存下次对话自动生效，无需重启。原配置项 ai.system-prompt 已并入该文件（升级自动迁移、配置项自动删除），knowledge 知识库文件夹方案由该文件取代
  • 新增：AI 网页爬取——默认关闭（测试功能）：开启后 AI 需要先看网页才能回答时可输出 [GET] 网址，插件抓取网页正文回传继续生成；仅 http/https 公网页，内网地址被拒绝（防 SSRF）；并修复网页读取失败时 AI 把访问代码 / 错误信息直接甩给用户的问题——失败统一按「网页暂时无法访问或没有返回内容」自然告知，技术原因只写日志；生产环境建议保持关闭
  • 新增：多服务器集群「查在线 / 查性能是否显示多个服务器」开关（bot.cluster.show-multi-cards，默认关）——开启后这两条命令（含别名 /在线）不再弹「选择服务器」按钮、无视群已选择，每台服务器各自渲染本服状态卡片，群里同时显示全部服务器的在线 / 性能状态
  • 调整：配置文件与官网教程清理版本号标注；表情包文件夹与提示词文件改为启动即自动生成；config-version 56 → 57（升级自动删废弃键，已改值不动）
