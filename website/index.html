更新日志

v1.7.4

2026-11-08 第三轮覆盖更新
  • 新增：QQ 多玩家绑定——每个 QQ 账号最多能绑定多少个玩家可配置（qq-bind.max-players-per-qq，默认 1 = 与旧版单绑定一致，只能填等于或大于 1 的整数，填 0 / 负数按 1 处理）。调大后一个 QQ 可绑定多个玩家；群里用玩家名片 / 查信息 / 重新绑定 / 签到这类需要找到“对应玩家”的指令时，机器人先列出该 QQ 名下的全部玩家让你点击按钮选择（旧版客户端不显示按钮时也可回复数字序号，2 分钟内有效）；@机器人 发数字不会被判定为 AI 对话。已达绑定上限时绑定码保留，解绑后重发同一码仍可绑定。
  • 修复：未开启 AI 功能时快捷面板仍出现 AI 指令按钮——ai.enabled 未开启时「AI对话上下文」「清除当前上下文」两个按钮不再出现在面板（旧版未接开关，未配置 AI 的服务器面板里也摆着两条不可用的 AI 指令）。
  • 修复：QQ 绑定关闭时签到命令仍可用——签到建立在 QQ-玩家绑定关系之上（签到天数 / 奖励都记在绑定的玩家档案里），绑定总开关 qq-bind.enabled 关闭时签到命令与面板按钮一并关闭（旧版只看签到自己的开关，绑定关闭后历史绑定数据仍可签到）。
  • 调整：移除旧命令 /金币榜——1.6.2 已更名 /财富榜，本轮官网 / 帮助 / 配置注释同步清理，命令只保留「财富榜」一个入口。
  • 调整：查在线多页图片每页重新抽背景图——在线人数多自动分多张图片时，每一页都从 img/ 自定义背景里重新随机抽一张（旧版整组页面共用同一张背景，图包里明明有很多张、感觉来来去去就几张）；在线排行榜 / 财富榜本就每页独立抽图；使用默认内置背景时观感不变，插件版 / 模组版统一生效。
  • 新增：QQ 机器人扫码登录——启动未配置凭据（bot.app-id / bot.secret）时自动进入扫码登录：控制台打印二维码与扫码链接，手机 QQ 扫码或复制链接打开确认后，AppID / Secret 自动写入配置并自动连接机器人，无需手动改文件；二维码过期自动刷新重发新码（连续过期 6 次回落教程引导）；/hbkrg qr 未配置凭据时随时重新发起。扫码授权链路参考同类产品 HuHoBot。
  • 调整：指令改名——「查询Open ID」更名为「查信息」（查自己的 / 群的 OpenId，配置 bot.groups 用；旧名 /查询open ID 及大小写变体仍可用）；原「查信息」玩家统计卡片更名为「玩家名片」（/玩家名片 @成员 可查他人；快捷面板与帮助同步更名）。
  • 新增：玩家死亡播报——player-events.death（默认关闭）：开启后玩家死亡向群播报，文案支持 {name} / {server} / {platform} 与 {message} 自动中文死亡描述（如「Steve 被苦力怕杀死了」）、{killer} 击杀者名（环境死亡为「未知」）；插件版与模组版统一生效。配置口径与 HuHoBot 一致。
  • 调整：多玩家选择与解除黑名单改为按钮交互——名下绑定多个玩家时的选择消息、/解除黑名单 的清单消息现在自带可点击按钮，点击即完成选择 / 解除（旧版 QQ 客户端不显示按钮时仍可回复数字序号；/解除黑名单 @成员 的直接解除路径保留）。交互模式参考 HuHoBot 的消息按钮。
  • 新增：多服务器集群——多台服务器共用同一个 QQ 机器人（相同 AppID）时，配置 bot.cluster 成员列表：群里执行命令先弹出「选择服务器」按钮（按钮名就是对应的服务器名），按下后该群的命令、聊天转发与播报都由所选服务器处理；新增 /切换服务器 指令随时重新选择（QQ 快捷面板同步增加该按钮，仅集群模式显示）。未配置（成员少于 2 个）时全部集群逻辑旁路，单服行为零变化。
  • 新增：服务器开关消息——server-notify 段（默认开启）：服务器正常关闭发「服务器已正常关闭」、窗口期内重启发「服务器已重启完成」、上次崩溃 / 强制结束后下次启动补发「意外关闭」；插件重载 / 手动停用不会误发；三类文案与开关均可配（支持 {server} / {platform} 占位符），配置口径与 HuHoBot 一致。
  • 新增：群自动绑定——bot.groups 留空时，把机器人拉进群后在群里发任意消息（命令 / 聊天均可），插件自动把该群 OpenId 写入白名单并重载配置（含快捷面板同步），无需手动抄群 ID、无需重启；已填写的配置不受影响。
  • 调整：旧版指令兜底下线——/查询open ID 及其大小写变体不再是 /查信息 的别名，指令只认现名。
  • 调整：教程二维码与教程链接输出移除——扫码登录失败时不再回落打印官网教程二维码；/hbkrg qr 已配置凭据时仅提示当前状态。
  • 配置版本 35 保持（新增 player-events.death 两键与按钮文案，升级自动补齐，旧配置无需改动）。

  • 修复：motd 展示人数不生效——render.performance.max-players-source = motd 时，查性能在线人数卡改为展示服务器列表里的实际展示值（人数与最大值一起生效，卡底注明「MOTD 展示值」）；插件按需对 127.0.0.1 本机自查询服务器列表取值（60 秒内复用结果，查不到回退真实值），插件版与模组版统一生效——旧版模组端配置写 motd 也永远显示服务器真实人数、插件端只换最大人数，都是不到位。
  • 调整：副标题灰色小标签回退 1.7.0 查在线同款固定灰——此前版本按背景亮度自动切换深浅两色的自适应配色整体移除，恢复固定的灰蓝色标签（22px 常规字重），观感与 1.7.0 查在线状态栏一致，不再随背景变化；查信息卡「玩家名称」标签同步回固定色。
  • 调整：副标题框默认灰度改为 80——旧默认 106 与项目卡相同、底色过重，图片信息密集（如排行榜）被缩小查看时副标题小灰字不清爽；80 与标题框 title-card-gray 相同，回归 1.7.0 轻卡观感；历史默认 40 / 56 / 106 升级时自动收敛，自行改过的值不动。
  • 配置版本 34，本轮无新增配置键，升级后无需改配置。

2026-11-05

  • 新增：副标题灰度 render.subtitle-card-gray（默认 56）——比标题框（80）和项目卡片（106）都浅；查信息玩家名称项卡片现在可以调了（旧版硬编码半透明白调不动）；旧默认 40 太浅看不出卡片底色，升级时自动收敛。
  • 新增：五张卡片副标题条（服务器 / 更新时间 / 渲染耗时，排行榜为展示玩家）——性能监控原服务器名小字移除，改由副标题条展示；渲染耗时展示从开始渲染到本图绘制完成的毫秒数（不是从接收指令开始算）；性能卡副标题条与标题框 / 指标容器上下等距（旧版只隔 4px）。
  • 新增：排行榜单页上限 leaderboard.page-size（全局，默认 20）——在线排行榜 / 财富榜共用，超出自动分多张图片发送（旧版固定 15）。
  • 新增：自定义图片渲染线程 render.custom-render-threads——开关（默认关闭 = 自动模式：渲染线程按 CPU 核数一半 1~4 条、头像下载 8 条）+ 渲染线程数 + 头像下载线程数（1-16）；⚠ 线程数越大 CPU 争抢越强，核数少的服务器可能影响游戏 tick，不建议超过物理核数一半；修改后需重启生效。
  • 修复：今日在线跨天误报——玩家全天没上线也显示旧日期的今日时长；现在按当前日期归零，下次上线正常重新累计。
  • 调整：主标题框上边距对齐查信息最上框——三张列表卡（查在线 / 排行榜 / 查性能）标题区 164 → 182，眉题视觉顶边距 27 → 45px（与查信息欢迎面板一致），主标题基线同步下移、底边距与眉题→主标题间距不变；副标题框零改动；右上角小方框与标题框四周留出 14px 可见间距（旧版上 / 下 8px、右侧 0px 与标题框齐平，看不出内嵌层次），框加高后卡内内容整体下移保持居中。
  • 调整：副标题条小标签自适应配色——「服务器 / 更新时间 / 渲染耗时 / 展示玩家」等小标签按卡底亮度自动切换：深色卡用柔和浅蓝灰、浅色卡自动换深蓝灰（20px 常规字重、无描边，五张卡片统一）——浅色自定义背景下清晰可读，深色卡上柔和不突兀（此前三轮调深、四轮近白 + 加粗 + 描边均不到位：四轮观感突兀，五轮自适应根治）。
  • 调整：排行榜副标题第三格「渲染耗时」改「展示玩家」——显示「TOP x」：本榜实际展示 min(统计玩家数, 显示上限) 名玩家（如 TOP 8，四轮起 TOP 在前，旧 xTOP 废弃）；查信息 / 查在线 / 查性能保留渲染耗时格。
  • 修复：内置字体缺「渲」字——「渲染耗时」曾显示成「染耗时」，字体子集已补齐。配置版本 30 → 32。
