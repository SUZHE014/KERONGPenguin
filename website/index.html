Fabric 模组版 1.7.5.5（MC 1.20.4–1.21.x，Java 21）

KERONGPenguin 的 Fabric 适配版——与 Spigot / NeoForge 版同源同功能：群聊互通 / 查询命令 / 信息卡渲染 / 绑定签到 / 服务器状态播报

  • 主线发版：随主线同号同步升版（与当前主线 1.7.5.5 完全对齐：/菜单 按钮菜单、按钮管理员平台门禁与验身标记、快捷面板管理员联动、菜单排版改版、扫码二维码按控制台编码自适应渲染、更新检查等）。
  • 已测试版本：1.20.4，1.20.5，1.20.6，1.21，1.21.4，1.21.6，1.21.11（各版本真实服务器启动验证）。
  • 支持版本：1.20.4–1.21.x（fabric.mod.json 声明 ≥1.20.4 <1.22——2026 年起的 26.x 新版本线未适配，明确排除）；Fabric Loader 0.15.1 及以上（Fabric API 的要求，实测下限 0.15.1；构建验证基于 0.16.14）；需另装 Fabric API（与所用 MC 版本对应即可）；Java 21。
  • QQ 绑定不拦截进服：未绑定玩家正常游玩，绑定完全自愿——游戏内发送 /hbkrg qbd 获取验证码，再到 QQ 群发送 /绑定 验证码 完成。
  • 更新检查：与插件版一致（启动后自动检查官网新版本，update-check.enabled 可关闭）。
  • 安装：与 Fabric API 一起放进 mods/ 即可；配置文件在 kerongpenguin/ 目录（首次启动生成），与插件版同结构可参考教程。
  • 已知差异：钓鱼 / 繁殖动物统计暂缺（Fabric API 无对应事件）。
